
# 🖼️ Imagens — Z80-EMU-PLUS

Esta pasta contém as imagens, diagramas e capturas de tela utilizadas na documentação e nos posts do projeto **Z80-EMU-PLUS**.

## 📂 Organização dos Arquivos

- **`z80_emu_plus_schematic.jpg`**: Esquema elétrico completo do mini computador (versão com periféricos), mostrando o PIC18F6722, as memórias, os decodificadores 74LS138 e as PPIs/USART.
- **`z80_emu_plus_base.jpg`**: Esquema da versão base (standalone), com foco no barramento, emulação de vetores e controles de WAIT/BUSREQ.
- **`emula_vetores.jpg`**: Detalhe do bloco de emulação de vetores (IM 0 e IM 2) com o Latch 74LS273 e o Buffer 74LS245.
- **`debug_terminal.jpg`**: Captura de tela do monitor de debug serial (UART) exibindo registradores, flags e estado do barramento em tempo real.

## 📝 Notas

- As imagens de esquema foram exportadas diretamente do **Proteus**.
